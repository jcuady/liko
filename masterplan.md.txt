5. Security & OWASP Compliance
Ensure the architecture strictly adheres to modern security protocols:

A01: Broken Access Control: Implement strict RBAC (Role-Based Access Control) checking user roles dynamically in Next.js Middleware before rendering /(dashboard) routes.

A02: Cryptographic Failures: Utilize secure, httpOnly, SameSite=Lax cookies for session tokens. Never expose tokens in localStorage.

A03: Injection: Validate all incoming data via Server Actions using strict Zod schemas before interacting with the API layer.

A04: Insecure Design: Implement rate limiting on sensitive API routes and authentication endpoints.

A07: Identification Failures: Force email verification before dashboard access. Implement standard CSRF protection.
